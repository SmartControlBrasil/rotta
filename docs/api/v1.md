# Rotta 116 Driver Mobile API v1

Versioned API endpoints under `/api/v1/` designed for the driver mobile application.

## Authentication

All endpoints (except `/api/v1/auth/token/`) require a Bearer/Token header authentication.

Header format:
```text
Authorization: Bearer <signed-token>
```
or
```text
Authorization: Token <signed-token>
```

Signed tokens are cryptographic, signed using the server's `SECRET_KEY`, and expire after 30 days.

---

## Endpoints Summary

### 1. Token Acquisition (Login)
* **Method:** `POST`
* **URL:** `/api/v1/auth/token/`
* **Authentication:** None
* **Request Body:**
  ```json
  {
    "username": "driver_username_or_email",
    "password": "driver_password"
  }
  ```
* **Success Response (200 OK):**
  ```json
  {
    "token": "ey..."
  }
  ```
* **Expected Errors:**
  * `400 Bad Request` if credentials parameters are missing.
  * `401 Unauthorized` if credentials are invalid.

### 2. User Profile (Me)
* **Method:** `GET`
* **URL:** `/api/v1/me/`
* **Authentication:** Required
* **Success Response (200 OK):**
  ```json
  {
    "id": "user-uuid",
    "username": "usera",
    "email": "usera@example.com",
    "driver": {
      "id": "driver-uuid",
      "full_name": "Driver A",
      "document": "12345678909"
    },
    "organization": {
      "id": "organization-uuid",
      "name": "Org A"
    },
    "capabilities": ["tracking.view", "tracking.start", "tracking.record", "tracking.end"]
  }
  ```
* **Expected Errors:**
  * `401 Unauthorized` if token is invalid or expired.
  * `403 Forbidden` if authenticated user is not linked to a driver profile.

  ```json
    "previous": null,
    "results": [

        "id": "operation-uuid",

  }
  ```

### 5. Advance Operation Status
* **Method:** `POST`
* **URL:** `/api/v1/driver/operations/<uuid>/advance-status/`
* **Authentication:** Required
* **Request Body:**
  ```json
  {
    "next_status": "DRIVER_EN_ROUTE_TO_PICKUP",
    "client_event_id": "optional-uuid-for-idempotency"
  }
  ```
* **Success Response (200 OK):**
  ```json
  {
    "id": "operation-uuid",
    "status": "DRIVER_EN_ROUTE_TO_PICKUP"
  }
  ```
* **Expected Errors:**
  * `409 Conflict` if the requested transition is not permitted by the state machine.

### 6. Report Incident
* **Method:** `POST`
* **URL:** `/api/v1/driver/operations/<uuid>/incidents/`
* **Authentication:** Required
* **Request Body:**
  ```json
  {
    "description": "Incident details...",
    "client_event_id": "optional-uuid-for-idempotency"
  }
  ```
* **Success Response (201 Created):**
  ```json
  {
    "id": "event-uuid",
    "event_type": "INCIDENT_REPORTED",
    "occurred_at": "2026-08-16T10:20:00Z"
  }
  ```

### 7. Record Proof Of Delivery (POD)
* **Method:** `POST`
* **URL:** `/api/v1/driver/operations/<uuid>/pod/`
* **Authentication:** Required
* **Request Body:**
  ```json
  {
    "receiver_name": "João Recebedor",
    "delivered_at": "2026-08-16T12:00:00Z",
    "latitude": -23.55,
    "longitude": -46.63,
    "notes": "Entregue perfeitamente."
  }
  ```
* **Success Response (201 Created):**
  ```json
  {
    "id": "pod-uuid",
    "status": "SUBMITTED",
    "receiver_name": "João Recebedor",
    "delivered_at": "2026-08-16T12:00:00Z"
  }
  ```
* **Expected Errors:**
  * `409 Conflict` if the operation is not in `UNLOADING` state or if a POD is already registered.

### 8. Start Telemetry Tracking
* **Method:** `POST`
* **URL:** `/api/v1/driver/operations/<uuid>/tracking/start/`
* **Authentication:** Required
* **Request Body:**
  ```json
  {
    "source": "mobile",
    "device_metadata": {
      "os": "Android",
      "version": "14"
    },
    "client_event_id": "optional-uuid"
  }
  ```
* **Success Response (201 Created):**
  ```json
  {
    "tracking_session_id": "session-uuid",
    "status": "ACTIVE",
    "started_at": "2026-08-16T10:15:23Z"
  }
  ```

### 9. Record Location Point
* **Method:** `POST`
* **URL:** `/api/v1/tracking/<session_uuid>/locations/`
* **Authentication:** Required
* **Request Body:**
  ```json
  {
    "latitude": -23.55052,
    "longitude": -46.633308,
    "accuracy_m": 8.2,
    "speed_kph": 47.5,
    "heading_deg": 132.0,
    "altitude_m": 760.0,
    "recorded_at": "2026-08-16T10:15:23Z",
    "sequence": 1234,
    "client_event_id": "optional-uuid"
  }
  ```
* **Success Response (201 Created):**
  ```json
  {
    "id": "location-uuid",
    "sequence": 1234,
    "recorded_at": "2026-08-16T10:15:23Z",
    "received_at": "2026-08-16T10:15:25Z"
  }
  ```
* **Expected Errors:**
  * `409 Conflict` if session is not ACTIVE, if operation is DELIVERED/CANCELLED, or if sequence/client_event_id duplicates.

### 10. Record Location Batch (Offline Sync)
* **Method:** `POST`
* **URL:** `/api/v1/tracking/<session_uuid>/locations/batch/`
* **Authentication:** Required
* **Request Body:** Array of location points (max 100 points per request).
  ```json
  [
    {
      "latitude": -23.551,
      "longitude": -46.634,
      "accuracy_m": 6.0,
      "sequence": 100,
      "client_event_id": "evt-b1"
    },
    {
      "latitude": -23.552,
      "longitude": -46.635,
      "accuracy_m": 5.5,
      "sequence": 101,
      "client_event_id": "evt-b2"
    }
  ]
  ```
* **Success Response (201 Created):**
  ```json
  {
    "success": true,
    "processed_count": 2,
    "results": [
      {
        "id": "uuid-1",
        "sequence": 100,
        "client_event_id": "evt-b1"
      },
      {
        "id": "uuid-2",
        "sequence": 101,
        "client_event_id": "evt-b2"
      }
    ]
  }
  ```

### 11. End Telemetry Tracking
* **Method:** `POST`
* **URL:** `/api/v1/tracking/<session_uuid>/end/`
* **Authentication:** Required
* **Success Response (200 OK):**
  ```json
  {
    "session_id": "session-uuid",
    "ended_at": "2026-08-16T11:00:00Z",
    "status": "ENDED"
  }
  ```
